Jogos com seus amigos, fora dos campeonatos. Quem é chamado aceita o convite. Depois do jogo, um informa o placar e o outro confirma.

{% call info_dialog('amistoso-regras', 'Quando o amistoso vale para o Ranking e o XP') %}
  • Os dois jogadores precisam já ter chegado a {{ rules.min_xp }} XP em campeonatos (Rank {{ rules.rank }}). O XP de amistosos não conta para isso. Quem chegou lá uma vez continua liberado, mesmo se perder XP depois. Assim, contas novas ou fake não conseguem dar XP para ninguém.{% if rules.my_peak < rules.min_xp %} Você ainda não chegou: seu maior XP em campeonatos é {{ rules.my_peak }}.{% else %} Você já está liberado.{% endif %}
  • Vale no máximo {{ rules.limit }} convites para amistosos por dia contra o mesmo adversário, mas vocês podem fazer quantos jogos quiserem dentro da mesma conexão. No fim, os dois confirmam os resultados.
  • Cada jogo vale sozinho no XP e no V/E/D, pelo placar dele. Com Placar agregado marcado no convite, o amistoso também mostra a soma dos gols de todos os jogos; sem ele, mostra só os jogadores. Depois de confirmado, o (i) de cada jogo mostra quanto XP ele deu.
  • Qualquer amigo pode ser convidado. Para o amistoso valer para o Ranking e o XP, marque Rankeado no convite: a opção só fica liberada quando os dois já chegaram ao Rank {{ rules.rank }} em campeonatos. Sem ela, os jogos contam só no card Amistosos do perfil.
  • Cada jogo do amistoso que vale entra no Ranking, no V/E/D e no XP como um jogo de campeonato, pelas mesmas regras. Ele não paga W$.
  • Se um não aceitar o placar, o amistoso fica suspenso até um dos dois propor um placar que o outro aceite.
