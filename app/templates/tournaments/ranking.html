Como funciona o Rank (XP)

Todo jogador começa no Rank F e sobe até o A juntando experiência (XP) nas partidas confirmadas de qualquer torneio. O rank aparece na foto de cada jogador.

  • Vitória contra alguém do mesmo rank: +{{ xp_rules.base }} XP para quem ganha e −{{ xp_rules.base }} XP para quem perde.
  • Ranks diferentes: cada nível de diferença muda {{ xp_rules.step }} XP. Ganhar de quem está acima vale mais (e ele perde mais); ganhar de quem está abaixo vale menos (no mínimo {{ xp_rules.min }} XP).
  • Empate no mesmo rank: ninguém ganha nem perde. Empate com rank diferente: o de rank menor ganha {{ xp_rules.step }} XP por nível de diferença e o outro perde o mesmo.
  • Jogo decidido nos pênaltis conta como empate. O XP nunca fica negativo, e perder XP pode fazer o jogador cair de rank.
