ISOs dos campeonatos

As ISOs identificadas de campeonatos publicados aparecem para os jogadores em "Enviar um Memory Card", na página da conta. ISOs novas (.bin, .iso, .img, .chd) são identificadas no envio; as enviadas antes disso, por este botão - pela cópia deste servidor ou pelo CRC32 que o archive.org lista para as migradas.
